Appearance & feedback

Keyboard

Browser-level shortcuts (work without opening the popup): Alt+Shift+F fill · Alt+Shift+C clear — rebind them in your browser’s extension shortcuts page.

Field types to fill

Turn a type off to leave those fields untouched — useful for avoiding passwords, file uploads or payments on live systems.

Per-field rules

Rules are matched top-to-bottom against each field’s label, name, placeholder and attributes. First match wins. Fixed values support tokens: {seq} {uuid} {ts} {date} {time} {rand:6} {first} {last} {email} {phone} {city} {country} {index}

Profiles

A profile is a full snapshot of settings + rules. Switch profiles from the popup, or let a site auto-pick one via URL patterns (*example.com*, *staging.*).

Import / Export

Bulk test-data generator

Generate CSV or JSON files using the current profile’s locale, ranges and data mode — for load testing, database seeding or API scripts.

Custom upload files

Used for <input type="file"> fields. Leave empty to use built-in demo files. Max 2 MB each.

Recent fills

Last 25 fills with per-field details — handy for verifying what actually got filled.
